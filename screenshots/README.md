# Screenshots

This folder contains visual evidence of the SQL Server database implementation.

## Evidence included

- `database-created.png`: shows the creation and selection of the database `BD_Tienda_Musica_Podcast`.
- `create-tables-example.png`: shows an example of the table creation script.
- `tables-created.png`: shows the list of the 18 tables created in SQL Server.
- `primary-keys-created.png`: shows the execution of primary key creation scripts.
- `primary-keys-validation.png`: shows the validation query listing the primary keys.
- `foreign-keys-created.png`: shows the execution of foreign key creation scripts.
- `foreign-keys-validation.png`: shows the validation query listing the foreign keys.
- `stored-procedure-created-example.png`: shows the creation of an insertion stored procedure.
- `stored-procedures-validation.png`: shows the validation query listing the 18 stored procedures.
- `stored-procedure-insert-example.png`: shows data insertion using a stored procedure.
- `data-inserted-roles.png`: shows inserted records in the Roles table.
- `function-created-example.png`: shows the creation of a scalar function.
- `functions-validation.png`: shows the validation query listing the database functions.
- `view-created-example.png`: shows the creation of a database view.
- `views-validation.png`: shows the validation query listing the database views.
- `trigger-created-example.png`: shows the creation of a trigger.
- `triggers-validation.png`: shows the validation query listing the database triggers.

## Purpose

These screenshots demonstrate that the database was created, populated, automated, and validated in SQL Server Management Studio.
